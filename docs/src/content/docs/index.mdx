## Packages

| Package | Registry | For |
|---|---|---|
| `pulzr-package` | [crates.io](https://crates.io/crates/pulzr-package), [API docs](https://docs.rs/pulzr-package) | writing a module in Rust: `cargo add pulzr-package` |
| `pulzr-pkg` | [PyPI](https://pypi.org/project/pulzr-pkg/) | the CLI and the host modules are tested in: `pipx install pulzr-pkg` |
| `pulzar-net/pulzr-package-sdk` | [GitHub Action](https://github.com/pulzar-net/pulzr-package-sdk/blob/main/action.yml) | building, testing and releasing a module from CI: `uses: pulzar-net/pulzr-package-sdk@v0.2.0` |
